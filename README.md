An enterprise-grade, multi-tenant biometric attendance and academic management ecosystem developed for **Rajiv Gandhi Institute of Technology (RGIT), Bangalore**. The system integrates **Deep Metric Computer Vision (128-d face embeddings)**, **GPS Geofencing (Haversine distance)**, **Dynamic Rotating QR Codes**, **Departmental Timetable Enforcement**, **Device Binding**, and **Role-Based Access Control (RBAC)** across web and mobile platforms.

## 🌟 Key System Features

1. **Facial Biometrics & Anti-Spoofing**:
   - 128-dimensional dlib ResNet face embeddings with Euclidean distance matching (`tolerance = 0.50`).
   - Multi-frame confirmation window (requires 5 consecutive matching frames) to prevent false positives.
   - Automatic capture of persistent unrecognized faces into `unknown_faces/` with security alerts.
2. **Dynamic QR Code Check-in**:
   - High-entropy rotating QR codes dynamically updated every session with single-use cryptographic tokens.
3. **GPS Geofencing**:
   - Validates student mobile device coordinates against campus GPS boundaries (Lat: `13.033090`, Lon: `77.597786`) with customizable radius thresholds using the Haversine formula.
4. **Hardware Device Binding**:
   - Prevents attendance proxying by tying student accounts to registered device signatures.
5. **Academic Timetable Matrix**:
   - Automated schedule enforcement across days, periods (Periods 1–7), and sections (A & B) with break locks (Short Break & Lunch Break).
6. **Multi-Tenant Department Architecture**:
   - Isolated SQLite databases with WAL (Write-Ahead Logging) per department (`attendance_CSE.db`, `attendance_AIML.db`, `attendance_ECE.db`, etc.).
7. **Role-Based Access Control (RBAC)**:
   - **Master Administrator**: Complete system configuration, department management, and security audit logs.
   - **Head of Department (HOD)**: Department timetable configuration, faculty oversight, and analytics.
   - **Faculty**: Attendance session management, QR display, live face kiosk, manual overrides, and Excel report export.
   - **Student**: Mobile attendance check-in, live schedule viewer, and individual attendance history.

## 🚀 Getting Started

### Prerequisites
- **Python 3.10+**
- **Node.js 18+** and **npm**
- **C++ Build Tools / CMake** (required by `dlib` if installing from source)

### 1-Click Quick Launch (Recommended on Windows)
Simply double-click:
```cmd
START_HOSTING.bat
```
This will:
1. Start the **FastAPI backend** on port `8000`.
2. Start the **Vite React frontend** on port `5173`.
3. Open the application directly in your default browser.

### Manual Launch

#### 1. Backend Server
```bash
python run_backend.py
```
*API will run at:* `http://localhost:8000`  
*Swagger Documentation:* `http://localhost:8000/docs`

#### 2. Frontend Application
```bash
cd frontend
npm install
npm run dev -- --host
```
*Web App will run at:* `http://localhost:5173`
